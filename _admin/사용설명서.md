# 대건엠에스 홈페이지 관리자 — 사용 설명서

## 1. 실행

`_admin` 폴더의 **`관리자 실행.cmd`** 를 더블클릭합니다.
검은 창이 하나 뜨고, 브라우저에 관리자 화면이 자동으로 열립니다.

| 주소 | 용도 |
|---|---|
| http://localhost:8880/admin/ | 관리자 |
| http://localhost:8880/ | 실제 사이트(미리보기) |

- **검은 창을 닫으면 관리자가 꺼집니다.** 작업하는 동안은 그대로 두세요.
- 이 관리자는 **내 PC 안에서만** 동작합니다. 인터넷에서는 접속할 수 없습니다.
- 8880 포트를 이미 쓰고 있다면 : `powershell -File _admin\server.ps1 -Port 8881`

## 2. 콘텐츠 수정 — 홈페이지 문구 고치기

1. 왼쪽에서 고칠 **페이지**를 고릅니다. (메인 + 서브 16페이지)
2. 가운데에 그 페이지의 문구가 **영역별로** 나옵니다. 고치고 싶은 칸을 수정합니다.
3. 오른쪽 **미리보기**에서 실제 모습을 확인합니다.
   - 칸을 클릭하면 미리보기에서 그 부분이 파랗게 표시됩니다.
   - 반대로 미리보기의 글자를 클릭하면 해당 편집 칸으로 이동합니다.
4. **저장하기** 를 누르면 사이트에 바로 반영됩니다.

### 알아두실 점
- **`<b>`, `<br>` 같은 표시가 보이면 지우지 마세요.** `<br>` 은 줄바꿈, `<b>` 는 굵게 표시입니다.
- `화면에 안 보임(읽기 지원용)` 표시가 붙은 칸은 시각장애인용 안내문입니다. 화면에는 안 나오지만 검색과 접근성에 쓰이므로 비우지 마세요.
- **상단 메뉴 · 하단 정보**는 메인 페이지에서 고치면 **전 페이지에 한꺼번에** 반영됩니다.
- 저장할 때마다 원본이 자동 보관됩니다. 잘못 고쳤으면 **배포 · 백업** 화면에서 되돌릴 수 있습니다.

## 3. 이미지 관리 — 사진 바꾸기

- 화면에 **이미지 자리 52곳**이 모두 나옵니다. 자리마다 **권장 크기와 어떤 사진이 들어가야 하는지** 적혀 있습니다.
  (예: `2560×1440 · 액티브웨어 착장 컷 · 딥네이비 오버레이 62%`)
- 사진을 **끌어다 놓거나 클릭**해서 고르면 바로 교체됩니다.
- `사진 설명` 칸은 검색엔진과 화면낭독기가 읽는 글입니다. 사진 내용을 짧게 적어주세요.
- 권장 크기보다 작은 사진을 넣으면 흐리게 보입니다. 되도록 권장 크기 이상으로 올려주세요.

> 로고는 브랜드 자산이라 이 화면에서 다루지 않습니다. 로고 교체가 필요하면 제작사에 요청하세요.

## 4. 문의 접수

### 지금 상태
홈페이지 문의 폼은 **관리자를 켜 둔 동안에만** 이 화면으로 들어옵니다.
관리자를 꺼 두면 방문자에게는 "메일로 보내주세요" 안내가 뜹니다.

**진짜로 24시간 문의를 받으려면 호스팅 업체의 접수 서버(PHP 등)가 필요합니다.**
서버가 준비되면 문의 폼의 접수 주소만 그 주소로 바꾸면 그대로 동작합니다.

### 쓰는 법
- 목록에서 문의를 고르면 오른쪽에 내용이 나옵니다.
- **신규 / 확인중 / 회신완료 / 보류** 로 상태를 관리합니다.
- 전화·메일로 받은 문의는 **직접 등록** 으로 같이 기록해 두면 한 곳에서 관리됩니다.
- **엑셀(CSV) 내려받기** 로 전체 목록을 엑셀에서 열 수 있습니다.
- 첨부파일은 `_admin\attachments` 폴더에 저장됩니다.

> ⚠️ 문의 내용에는 고객 개인정보가 들어 있습니다. `_admin\data\inquiries.json` 과 `_admin\attachments` 는 **GitHub에 올라가지 않도록 제외**되어 있습니다. 이 파일들을 다른 곳으로 옮기거나 공유하지 마세요.

## 5. 공지 · 자료실

- **공지사항** 과 **자료실** 두 개 게시판이 홈페이지 `News` 메뉴에 연결되어 있습니다.
- **새 글 쓰기** → 제목 · 날짜 · 내용을 적고 **저장하고 사이트에 반영** 을 누르면 끝입니다.
- 글쓰기 요령
  - 엔터로 줄바꿈, **빈 줄**로 문단이 나뉩니다.
  - `**강조할 말**` 처럼 별표 두 개로 감싸면 굵게 나옵니다.
  - 주소(`https://…`)를 그대로 적으면 자동으로 링크가 됩니다.
- **목록 맨 위에 고정** 을 켜면 공지 배지가 붙고 항상 위에 노출됩니다.
- **홈페이지에 공개** 를 끄면 글은 보관되지만 사이트에는 안 나옵니다. (초안 보관용)
- 첨부파일은 `files` 폴더에 저장되고, 상세 페이지에서 내려받을 수 있습니다.

## 6. 배포 · 백업

### 사이트에 올리기
수정한 내용을 인터넷에 공개합니다. 무엇을 바꿨는지 한 줄 적고 **사이트에 올리기** 를 누르면
1~2분 뒤 https://seyeong1403.github.io/DAEKUN/ 에 반영됩니다.

> 지금은 **임시 검토용 주소**입니다. 정식 도메인(daekunms.co.kr) 연결은 별도 작업입니다.

### 되돌리기
저장할 때마다 원본이 자동 보관됩니다. 목록에서 시점을 골라 되돌릴 수 있습니다.
되돌리기 직전 상태도 새 백업으로 남으므로, 되돌린 것을 다시 되돌릴 수도 있습니다.

## 7. 공개 전에 반드시 할 것

대시보드 아래쪽 **공개 전 확인할 것** 목록과 같습니다.

1. ~~검색엔진 색인 차단(noindex) 해제~~ → **완료.** 전 페이지에서 제거하고 `robots.txt`·`sitemap.xml` 을 공개용으로 바꿨다
2. 약관 · 개인정보처리방침의 `[ 대괄호 ]` 자리 채우기 (시행일, 수탁업체명, 책임자 성명·직위)
3. 문의 폼 접수 서버 연결
4. 실제 주소가 `daekunms.co.kr` 이 아니면 `sitemap.xml` 과 각 페이지 `og:url`·`og:image` 의 도메인 교체

## 8. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 검은 창에 "포트를 열 수 없습니다" | 관리자가 이미 실행 중입니다. 기존 창을 닫고 다시 실행하세요. |
| 화면이 이상하게 나온다 | 브라우저에서 `Ctrl + Shift + R` 로 새로고침하세요. |
| 잘못 저장했다 | **배포 · 백업 → 자동 백업** 에서 되돌리세요. |
| 미리보기가 안 바뀐다 | 저장 후 자동으로 새로 불러옵니다. 그래도 안 되면 새로고침하세요. |

## 9. 폴더 구조 (참고)

```
daekunms/
 ├ index.html            메인 (여기의 상단 메뉴·하단 정보가 전 페이지 원본)
 ├ about/ business/ …    자동 생성되는 서브 페이지 — 직접 고치지 마세요
 ├ news/                 공지·자료실 (관리자가 자동 생성)
 ├ css/ js/ images/      디자인 자산
 ├ files/                게시판 첨부파일
 ├ _build/pages/         서브 페이지 본문 원본 ← 관리자가 여기를 고칩니다
 └ _admin/               관리자 (사이트에는 올라가지 않음)
     ├ 관리자 실행.cmd
     ├ data/             문의·게시글 데이터
     ├ attachments/      문의 첨부파일
     └ backups/          자동 백업
```

**`about/`, `business/` 같은 폴더의 HTML 을 직접 고치면 다음 저장 때 덮어써집니다.**
반드시 관리자를 통해 수정하세요.
