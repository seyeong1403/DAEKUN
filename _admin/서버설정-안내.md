# 서버 담당자께 — 배포 전 nginx 설정 요청

이 저장소는 1Panel 서버(`daekun.vigo.co.kr`)의 문서 루트로 그대로 `git pull` 되므로,
아래 폴더가 **웹에서 그대로 열립니다.** nginx 에서 막아 주세요.

## 막아야 하는 경로

| 경로 | 내용 |
|---|---|
| `/_admin/` | 관리자 도구 (내부용) |
| `/_build/` | 페이지 조각 · 빌드 스크립트 |
| `/_qa/` | 검수 도구 |
| `/_ref/` | 작업 참고 자료 |
| `/.git/` | **저장소 전체 이력. 가장 위험합니다** |

`robots.txt` 로 색인은 막아 뒀지만, 그건 검색엔진에만 해당하고 직접 주소를 치면 열립니다.

## nginx 설정

사이트 설정의 `server { }` 안에 넣어 주세요.

```nginx
# 내부 작업 폴더 · git 이력 차단
location ~ ^/(_admin|_build|_qa|_ref)/ {
    deny all;
    return 404;
}
location ~ /\.git {
    deny all;
    return 404;
}

# robots.txt · sitemap.xml 은 열려 있어야 한다
location = /robots.txt { allow all; }
location = /sitemap.xml { allow all; }
```

적용 후 아래가 모두 **404** 여야 정상입니다.

```
https://daekun.vigo.co.kr/_admin/ui/index.html
https://daekun.vigo.co.kr/_build/pages/01-about-overview.html
https://daekun.vigo.co.kr/.git/config
```

## 참고 — 관리자는 이 서버에서 동작하지 않습니다

관리자(`_admin/`)는 담당자 PC에서 PowerShell 로 실행하는 도구입니다.
서버에 올라가더라도 화면만 뜨고 기능은 동작하지 않습니다. 저장소 관리 편의를 위해 함께 두는 것이므로,
웹에서는 차단해 주시면 됩니다.
