# 대건엠에스 홈페이지 관리자 — 카페24 설치 안내

기존 관리자(PowerShell, 담당자 PC 전용)를 **PHP로 다시 만든 것**입니다.
카페24 서버에 올리면 누구나 인터넷 주소로 접속해서 쓸 수 있습니다.

기능은 예전과 같습니다. 대시보드 · 콘텐츠 수정 · 이미지 관리 · 문의 접수 · 공지/자료실 · 되돌리기.

---

## 1. 필요한 환경

| 항목 | 필요 조건 |
|---|---|
| PHP | **7.4 이상** (카페24 웹호스팅 기본으로 충족) |
| 확장 | `json` 만 필수. `mbstring` · `gd` 는 있으면 쓰고 없어도 동작 |
| 데이터베이스 | **필요 없음** (JSON 파일로 저장) |

---

## 2. 올리는 위치

FTP로 접속해 **홈페이지 파일들이 있는 폴더**(보통 `/www/`)에 이 폴더를 통째로 올립니다.
폴더 이름은 `_admin` 을 권합니다.

```
/www/                     ← 홈페이지 루트
   index.html
   about/  business/  products/  ...
   css/  js/  images/
   _build/                ← 페이지 조각 (반드시 함께 올릴 것)
   _admin/                ← 이 폴더
      index.php
      api.php
      inquiry.php
      config.php
      tool-hash.php
      lib/
      ui/
      data/
      backups/
      attachments/
```

폴더 이름은 `_admin` 이 아니어도 됩니다. 코드가 **자기 부모 폴더를 사이트 루트로 인식**하므로,
홈페이지 파일 바로 아래에만 두면 이름은 자유입니다.

> `_build/` 폴더를 빼먹으면 **콘텐츠 수정이 동작하지 않습니다.** 서브 페이지의 원본이 여기 있습니다.

---

## 3. 폴더 권한

아래 3개는 서버가 파일을 써야 하므로 권한을 풀어 줍니다. (FTP 프로그램에서 속성 변경)

| 폴더 | 권한 |
|---|---|
| `_admin/data` | **707** |
| `_admin/backups` | **707** |
| `_admin/attachments` | **707** |

홈페이지 파일도 관리자가 고쳐야 하므로, 아래도 쓰기가 되어야 합니다.

- `index.html`, `about/`, `business/`, `products/`, `quality/`, `contact/`, `etc/`, `news/`
- `_build/pages/`
- `images/content`, `images/common`, `images/main`
- `files/` (게시판 첨부. 없으면 자동으로 만들어짐)

권한이 부족하면 저장할 때 **"파일을 저장할 수 없습니다 (폴더 권한을 확인하세요)"** 가 뜹니다.

---

## 4. 비밀번호 바꾸기 — 가장 먼저 할 일

기본 계정이 들어 있습니다. **반드시 바꿔 주세요.**

```
아이디   admin
비밀번호 DaekunMS!2026
```

바꾸는 방법

1. 브라우저로 `https://도메인/_admin/tool-hash.php` 를 엽니다
2. 쓰고 싶은 비밀번호를 넣고 `만들기` 를 누릅니다
3. 나온 한 줄을 `config.php` 의 같은 줄과 바꿉니다
4. **`tool-hash.php` 를 서버에서 지웁니다** (남겨 두면 누구나 열 수 있습니다)

아이디도 바꾸려면 `config.php` 의 `ADMIN_USER` 를 고칩니다.

---

## 5. 문의 폼 연결 (선택)

방문자 문의를 관리자에서 받으려면 한 줄만 바꾸면 됩니다.

`_build/pages/13-contact-inquiry.html` 에서

```html
<form id="inquiryForm" ... data-endpoint="/api/inquiry" ...>
```

를 아래로 바꿉니다.

```html
<form id="inquiryForm" ... data-endpoint="/_admin/inquiry.php" ...>
```

바꾼 뒤 관리자에서 `되돌리기 · 백업 → 전체 다시 만들기` 를 누르면 실제 페이지에 반영됩니다.
(또는 `contact/inquiry.html` 을 직접 고쳐도 됩니다)

연결되면 대시보드의 확인 목록에서 초록색으로 바뀝니다.

문의가 들어올 때 메일로도 받으려면 `config.php` 의 `INQUIRY_MAIL_TO` 에 주소를 넣습니다.

## 6. 예전 관리자와 달라진 점

| | 예전 (PowerShell) | 지금 (PHP) |
|---|---|---|
| 어디서 열리나 | 담당자 PC 에서만 | **인터넷 주소로 어디서나** |
| 실행 방법 | `관리자 실행.cmd` 두 번 클릭 | 그냥 주소 접속 |
| 로그인 | 없음 | **아이디 · 비밀번호** |
| 사이트 반영 | GitHub 에 올려야 반영 | **저장하면 즉시 반영** |
| 문의 폼 | 연결 불가 | **연결 가능** |

`사이트 반영` 메뉴는 `되돌리기 · 백업` 으로 바뀌었습니다.
카페24에서는 파일이 곧 사이트라서 따로 올릴 것이 없습니다.

## 7. 보안 — 서버 담당자 확인 사항

관리자와 데이터가 인터넷에 열려 있으므로 아래를 확인해 주세요.

**1) 데이터 폴더 차단**

`data` · `backups` · `attachments` 에 `.htaccess` 를 넣어 뒀습니다. 아파치라면 그대로 동작합니다.
nginx 라면 아래를 추가해 주세요.

```nginx
location ~ ^/_admin/(data|backups|attachments)/ { deny all; return 404; }
location ~ ^/(_build|_qa|_ref)/            { deny all; return 404; }
location ~ /\.git                          { deny all; return 404; }
```

`data` 폴더에는 **문의자 개인정보**가 들어갑니다. 반드시 막아야 합니다.

**2) HTTPS**

로그인 비밀번호가 오가므로 `https` 를 켜 주세요. 카페24에서 무료 인증서를 제공합니다.
`https` 로 접속하면 로그인 쿠키가 자동으로 `Secure` 로 설정됩니다.

**3) 지워야 하는 파일**

- `tool-hash.php` — 비밀번호 설정이 끝나면 삭제
- `__shot.php` — 있으면 삭제 (개발 중 화면 촬영용)

## 8. 이미 들어 있는 보호 장치

- 로그인 없이 API 호출 → 차단 (401)
- 다른 사이트에서 몰래 요청 → 차단 (CSRF 토큰)
- `../` 로 폴더 밖 접근 → 차단
- `.php` 등 실행 파일 업로드 → 차단
- 로그인 4시간 후 자동 만료
- 비밀번호 틀리면 1초 지연 (무작위 대입 방지)
- 문의 폼 같은 IP 1분에 3건 제한
- 관리자 전 페이지 `noindex` (검색에 안 잡힘)

---

## 9. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 화면이 하얗게 나옴 | PHP 버전이 7.4 이상인지. 카페24 관리에서 변경 |
| 저장이 안 됨 | 3번의 폴더 권한 |
| 콘텐츠 수정에 페이지가 안 보임 | `_build/pages/` 를 올렸는지 |
| 로그인이 계속 풀림 | 세션 폴더 권한. 카페24 기본값이면 문제 없음 |
| 이미지가 안 올라감 | `images/content` 권한, 파일 크기 10MB 이하 |

---

## 10. 참고 — 이 관리자가 하는 일

관리자는 **정적 HTML 파일을 직접 고칩니다.** 데이터베이스를 쓰지 않습니다.

- 서브 페이지는 `_build/pages/` 의 조각을 고친 뒤 `index.html` 의 헤더·푸터와 합쳐 생성합니다
- 공지·자료실은 `data/posts.json` 을 읽어 `news/` 아래 페이지를 만듭니다
- 저장할 때마다 이전 파일이 `backups/` 에 복사됩니다

그래서 관리자를 지워도 홈페이지는 그대로 동작합니다.
